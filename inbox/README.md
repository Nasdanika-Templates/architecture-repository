# Inbox

Raw inputs for the AI assistant: reviewed meeting transcripts, notes, e-mail threads, vendor answers.
Name files by date and subject, for example `2026-10-28-kickoff-transcript.txt`.

Review a file before you add it: remove what must not be stored, such as personal remarks and
confidential matters outside the project, and correct misheard names and terms. Facts in the
document cite these files as their sources, so keep them once they are converted.
