[#prompt-tips]
== Tips

* *Point at files, not at memory.* "Read `inbox/...`" beats pasting, and the file stays as the
  source.
* *One concern per session.* Convert the meeting, review and commit; then update the repository,
  review and commit. Smaller diffs are reviewed better.
* *Ask for the uncertainty.* End with "what were you unsure about?" The answer is often the most
  useful part.
* *Make the build the referee.* Ask the assistant to run `mvn clean package` and fix what fails.
  A green build does not prove the content right, but a red one proves it wrong.
