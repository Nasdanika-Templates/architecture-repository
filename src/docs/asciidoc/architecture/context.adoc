[#context]
= System Context

_C4 level 1. ADM Phase A._

The {system} of the C4 model's example lets personal banking customers view their accounts and
make payments. It gets account information from, and makes payments through, the Mainframe Banking
System, and sends e-mail through the bank's Microsoft Exchange system. The {feature} is a new
capability inside the {system}; <<context-diagram>> shows the context with the new external
dependencies it brings.

[#context-new]
== What Is New

[cols="2,4"]
|===
|Element |Role in the {feature}

|Azure OpenAI
|[.decision]#DECISION# The only source of language models (<<adr-001>>). Provides the chat model that
writes the answers and the embedding model that indexes the content.

|Contact Center Platform
|Receives the handover: the conversation so far and the customer's identity. The platform and its
API are [.assumption]#ASSUMPTION# able to accept chats from an external channel (<<a-04>>).

|Content Management System
|The source of the approved content the assistant answers from. Only published content is ingested.

|Contact Center Agent
|A new actor in the context: takes over conversations the assistant hands over.
|===

The Mainframe Banking System and the E-mail System are unchanged. The assistant reaches the
mainframe only through the existing API application, read-only (<<adr-005>>).
