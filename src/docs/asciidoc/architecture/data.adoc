[#data-principles]
== Principles

* *Index the public, fetch the personal.* Only approved content goes into the vector index.
  Customer data is fetched per question, through the API application, under the customer's own
  session, and is never embedded or indexed. This keeps the index free of personal data and keeps
  the existing entitlements in force (<<adr-002>>).
* *Nothing trains a model.* Prompts, completions and conversations are not used to train or
  fine-tune models (<<adr-006>>). [.assumption]#ASSUMPTION# The bank's Azure OpenAI agreement and
  configuration exclude use of the data by the provider for training, and abuse monitoring is
  configured per the bank's policy (<<a-02>>).
* *Minimize what is logged.* Telemetry carries identifiers and metrics, not message text; the
  conversation store is the only place the text is kept.

[#ingestion]
== Content Ingestion

Published content is exported from the Content Management System, split into passages along its
headings, embedded with the chosen embedding model (<<embedding-models>>) and indexed with its
metadata: product, audience, effective date and URL. Re-ingestion runs on every publication.
Content that is withdrawn is removed from the index in the same run, so the assistant cannot cite
it.
